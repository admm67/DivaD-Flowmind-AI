# References, inspiration, and licence notes

FlowMind AI is independently authored. It uses general management concepts
associated with Theory of Constraints, systems thinking, queueing, project
management, and decision analysis. It does not copy source code or proprietary
text from the projects below.

## Inspiration repositories
1. https://github.com/zharikovpro/logical-thinking-process-skill — guided
   five-phase Logical Thinking Process skill; repository declares MIT.
2. https://github.com/rafaelnasch/goldratt-skill — modular Goldratt/TOC skill
   architecture and progressive loading; no licence declared in repository
   metadata when reviewed. No code/text/assets copied.
3. https://github.com/oenvown/flow_game — educational simulation of dependent
   operations and statistical fluctuation; no licence declared in repository
   metadata when reviewed. FlowMind's simulator is a new implementation.
4. https://github.com/ironyjk/toc-agents — TOC-oriented agent workflows;
   repository declares MIT. No source files copied.
