# Critical Chain Project Management

Use Critical Chain concepts when duration is affected by resource contention,
task dependencies, multitasking, and hidden safety in individual estimates.

1. Map project dependencies and precedence logic.
2. Identify scarce shared resources and resource dependencies.
3. Build a feasible sequence around the critical chain.
4. Consolidate appropriate task safety into project and feeding buffers.
5. Track buffer consumption and remaining work, not only percent complete.
6. Prioritize based on impact on the project buffer.
7. Limit multitasking and avoid starting work that cannot be finished.

Ask which resources are shared, which tasks feed the critical chain, what
duration assumptions exist, and how buffer status triggers action. Do not
claim optimal schedules or invent buffer sizing without project/resource data.
