# Logical Thinking Process

Use the five tools as a connected sequence when the problem warrants it.
These are qualitative reasoning tools, not substitutes for measurement.

## Current Reality Tree (CRT)
Purpose: explain multiple undesirable effects (UDEs) through underlying causes.
1. State UDEs as observable conditions, not proposed causes.
2. Write causal links as IF cause THEN effect.
3. Check whether a cause is sufficient, necessary, or merely correlated.
4. Connect branches only when defensible; attach evidence and confidence.
5. Identify competing explanations and tests that could falsify the diagnosis.
Do not label the earliest item in a chain as a proven root cause.

## Evaporating Cloud (EC)
Purpose: surface a conflict between two actions that appear necessary for a
shared objective. Map A (objective), B/C (requirements), D/D-prime (actions).
For each arrow, state the assumption that makes the relationship appear
necessary. Challenge whether it is always true, evidence-based, or a policy
rather than a physical law. An injection is a practical, testable condition
that breaks a key assumption; it is not just a slogan.

## Future Reality Tree (FRT)
Start with the injection and trace if-then links to desired effects. Check
whether UDEs are neutralized. Identify negative branch reservations (NBRs),
add safeguards, and define leading indicators and a pilot.

## Prerequisite Tree (PRT)
List obstacles to the desired change. For each, define an intermediate
objective that removes the obstacle. Sequence by dependency and define
evidence of completion.

## Transition Tree (TT)
Convert intermediate objectives into actions:
"I will do [action] because [reason/condition], which should create [effect]."
Capture owner, trigger/date, inputs, expected output, verification, and fallback.

## Facilitation
In collaborative work, proceed one phase at a time and ask for confirmation
at meaningful gates. If the user requests a full first draft, label it
provisional and mark unvalidated assumptions.
